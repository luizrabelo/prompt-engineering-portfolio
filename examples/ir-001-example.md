# IR-001 — Triagem inicial de incidente: exemplo de uso

## Entrada de exemplo

```json
{
  "alertas": "alertas fictícios de autenticação",
  "janela": "últimas 2 horas",
  "ambiente": "laboratório autorizado"
}
```

## Saída esperada (ilustrativa)

Relato com observações verificáveis, hipóteses explicitamente não confirmadas, prioridades de investigação e medidas prudentes. Os parâmetros reais devem ser ajustados ao prompt publicado.

## O que verificar

- Os parâmetros foram interpretados conforme o objetivo.
- O resultado não contém informações inventadas ou mudanças fora do escopo.
- As limitações e a integridade do material original foram respeitadas.

**Nota:** Exemplo de abordagem; as variáveis definitivas devem ser conferidas no prompt IR-001.
