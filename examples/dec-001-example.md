# DEC-001 — Pré-mortem estratégico: exemplo de uso

## Entrada de exemplo

```json
{
  "decisao": "substituir fornecedor de software",
  "objetivo": "reduzir custo anual sem elevar indisponibilidade",
  "horizonte": "12 meses",
  "premissas": "migração de dados concluída em 90 dias",
  "restricoes": "sem parada superior a 2 horas",
  "tolerancia_risco": "baixa"
}
```

## Saída esperada (ilustrativa)

Matriz com pelo menos cinco mecanismos distintos de fracasso, sinais precoces e medidas de mitigação, incluindo cenários de reversão. Probabilidades numéricas não aparecem sem evidência.

## O que verificar

- Os parâmetros foram interpretados conforme o objetivo.
- O resultado não contém informações inventadas ou mudanças fora do escopo.
- As limitações e a integridade do material original foram respeitadas.

**Nota:** Saída ilustrativa, sem diagnóstico de fornecedor real.
