# IMG-024 — Tira de cabine: exemplo de uso

## Entrada de exemplo

```json
{
  "foto": "uma pessoa, foto frontal autorizada",
  "expressoes": "neutra, sorriso, surpresa, piscadela",
  "fundo": "cinza-claro",
  "orientacao": "vertical",
  "acabamento": "impressão fosca"
}
```

## Saída esperada (ilustrativa)

Exatamente quatro quadros alinhados, com identidade e roupas consistentes; expressão varia na sequência e as bordas ficam uniformes.

## O que verificar

- Os parâmetros foram interpretados conforme o objetivo.
- O resultado não contém informações inventadas ou mudanças fora do escopo.
- As limitações e a integridade do material original foram respeitadas.

**Nota:** Não inclui quatro fotos geradas; descreve o critério de aceite.
