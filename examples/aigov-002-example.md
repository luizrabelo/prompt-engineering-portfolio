# AIGOV-002 — Due diligence de fornecedor de IA: exemplo de uso

## Entrada de exemplo

```json
{
  "proposta_fornecedor": "proposta hipotética sem documentação de segurança",
  "requisitos_negocio": "análise de documentos",
  "requisitos_segurança": "retenção, controle de acesso e logs",
  "restricoes_regulatorias": "políticas internas aplicáveis",
  "dados_processados": "documentos de uso interno",
  "sla_esperado": "definido no contrato"
}
```

## Saída esperada (ilustrativa)

Questionário de segurança, mapa de alegações sem evidência e plano de prova de conceito. Nenhuma aprovação de fornecedor é assumida.

## O que verificar

- Os parâmetros foram interpretados conforme o objetivo.
- O resultado não contém informações inventadas ou mudanças fora do escopo.
- As limitações e a integridade do material original foram respeitadas.
