# IMG-035 — Produto para e-commerce: exemplo de uso

## Entrada de exemplo

```json
{
  "foto": "fotografia de uma caneca própria sem marca",
  "produto": "caneca branca de cerâmica",
  "fundo": "branco neutro",
  "luz": "softbox lateral suave",
  "cor_referencia": "branco neutro com alça original",
  "formato": "quadrado 1:1"
}
```

## Saída esperada (ilustrativa)

Caneca mantém forma e marcas físicas reais, com luz difusa, sombra de contato e fundo limpo; nenhum texto ou alça extra aparece.

## O que verificar

- Os parâmetros foram interpretados conforme o objetivo.
- O resultado não contém informações inventadas ou mudanças fora do escopo.
- As limitações e a integridade do material original foram respeitadas.

**Nota:** Visualização-alvo, não fotografia de teste.
