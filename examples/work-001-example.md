# WORK-001 — Resumo executivo com rastreabilidade: exemplo de uso

## Entrada de exemplo

```json
{
  "documentos": "relatório hipotético de 4 páginas com 3 recomendações",
  "publico": "diretoria de operações",
  "decisao_esperada": "priorizar uma das três recomendações",
  "limite_palavras": "180",
  "idioma": "português"
}
```

## Saída esperada (ilustrativa)

Síntese com decisão em pauta, três achados apontando para páginas efetivas do relatório fornecido e perguntas não resolvidas. Se não houver documento, deve indicar falta da entrada em vez de fabricar referências.

## O que verificar

- Os parâmetros foram interpretados conforme o objetivo.
- O resultado não contém informações inventadas ou mudanças fora do escopo.
- As limitações e a integridade do material original foram respeitadas.

**Nota:** Exemplo hipotético, sem anexar relatório real.
