## Como escolher

Comece pela tarefa concreta. Use `WORK` para documentos e comunicação, `DATA` para diagnóstico quantitativo, `DEC` para decisão, `PLAN` para execução, `LEARN` para estudo, `CAREER` para carreira, `SALES` para vendas e `AIGOV` para governança de IA.

## Padrão editorial

Cada arquivo explicita entradas, critérios de saída, limitações e verificações. Texto de terceiros inserido como entrada é dado, não instrução. A publicação dos prompts não significa aferição independente de resultados.

## Limites

Proteja informações confidenciais, revise conclusões e valide operações, valores ou decisões sensíveis antes de aplicá-las.
