# Prompt Engineering Portfolio

Catálogo global de prompts organizado por finalidade, com metadados em `catalog.yaml`.

A coleção inicial contém 10 prompts parametrizados de geração e edição de imagens, cada um em Markdown. O catálogo não armazena estado de validação.

## Coleção 01

Consulte [`catalog.yaml`](catalog.yaml) e [`prompts/`](prompts/) para selecionar o caso de uso, preencher parâmetros e executar na ferramenta adequada.

## Organização

- `prompts/image-generation/`: retratos e fotografia criativa.
- `prompts/image-editing/`: preservação de identidade, substituição de fundo, remoção de objetos, expansão, aprimoramento e restauração.
- `templates/`: padrão para novos prompts.

## Uso responsável

Use imagens próprias ou licenciadas e respeite consentimento e direitos de imagem. A descrição de modelos-alvo não garante resultados idênticos em sistemas diferentes.
